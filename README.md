# Gereta AI Chat

PC 우선 한국어 캐릭터 채팅 앱의 개발용 첫 버전입니다. Node.js 22 이상에서 외부 패키지 없이 실행됩니다.

```sh
npm install --package-lock-only --ignore-scripts
npm test
npm run dev
```

기본 포트는 3000입니다. `.env.example`을 참고해 선택적으로 `.env`에 `GERETA_AI_KEY`와 `GERETA_AI_MODEL`을 설정하면 서버가 OpenAI API로 실제 답변을 요청합니다. 키를 Git에 올리지 마세요. 키가 없으면 메시지는 저장되지만 실제 AI 답변은 생성하지 않습니다.

## 구현 범위

- 기본 여성 4명·남성 4명, 프리미엄 캐릭터 2명
- 캐릭터 탐색·필터, 사용자 캐릭터 제작
- 실제 AI 요청, 브라우저별 대화 기록과 프로필 저장
- 프리미엄 체험 및 현재 프로필에 무료 부여하는 관리자 체험
- PC 우선 레이아웃과 작은 화면 대응

## 배포 전 필요한 작업

실제 회원가입·로그인, 서버 데이터베이스, 서버에서 검증하는 관리자/프리미엄 권한, 결제 연동은 아직 구현되지 않았습니다. 관리자 체험은 누구나 변경할 수 있는 로컬 시연입니다. 캐릭터와 대화는 다른 사용자에게 공유되지 않습니다. 브라우저 저장 용량은 유한하며 데이터 삭제 시 기록이 사라집니다. 메시지 횟수 제한은 두지 않지만 AI에는 최근 30개 메시지만 전달합니다. AI 요청에 서버 인증·요청 제한이 없으므로 API 키를 연결한 상태로 공개 인터넷에 배포하지 마세요. 공개 전 인증, 남용 방지, 사용량 관리, 개인정보 처리 방침을 추가해야 합니다.

API 키를 설정하지 않은 상태에서도 UI 개발이 가능합니다. `npm test`는 페이지 제공, 설정 상태, AI 미설정 오류 및 경로 접근 제한을 검사합니다.
